# Jorge Portfolio

Portafolio profesional de Jorge Rodrigo Masson Reynoso, construido como una aplicacion web independiente con React Native Web y Vite.

## Stack

- React
- React Native Web
- TypeScript
- Vite

## Caracteristicas

- Contenido bilingue en ingles y espanol.
- Navegacion interna por secciones.
- Diseno sobrio y profesional.
- Secciones de perfil, experiencia, proyectos, stack tecnico, educacion y contacto.
- Foto de perfil integrada como asset local.
- Arquitectura inspirada en practicas de React Native: `screens`, `components`, `hooks`, `models`, `utils` y `assets`.

## Requisitos

- Node.js
- npm

## Instalacion

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

La aplicacion corre por defecto en:

```text
http://localhost:5174
```

## Build

```bash
npm run build
```

El resultado de produccion se genera en:

```text
dist/
```

## Preview de produccion

```bash
npm run preview
```

## Estructura

```text
src/
  assets/
  components/
    PortfolioComponents/
    UI/
  hooks/
  models/
  screens/
  utils/
    constants/
```
